# Financial Risk Analysis using Python

## Overview

This project focuses on analyzing customer transaction data to identify financial risks, customer behavior, overdrafts, suspicious transactions, and account stability using Python.

## Features

✔ Data Cleaning & Preprocessing
✔ Customer Segmentation
✔ Financial Risk Assessment
✔ Anomaly Detection (IQR & Z-score)
✔ Hypothesis Testing
✔ Data Visualization using Matplotlib & Seaborn

## Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

## Project Workflow

Raw Dataset → Data Cleaning → Exploratory Data Analysis → Customer Segmentation → Risk Detection → Hypothesis Testing → Visual Analytics

## Key Analysis

* Credit vs Debit Trend Analysis
* Overdraft Detection
* Suspicious Transaction Identification
* Balance Volatility Analysis
* Customer Risk Segmentation

## Visualizations

* Line Charts
* Bar Charts
* Histograms
* Scatterplots
* Heatmaps

## Key Insights

* High withdrawal frequency customers showed greater financial risk.
* Frequent overdrafts indicated unstable financial behavior.
* Statistical testing revealed transaction behavior patterns.
